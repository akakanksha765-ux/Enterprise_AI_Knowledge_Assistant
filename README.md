Enterprise AI Knowledge Assistant uses RAG, LangChain, FAISS, BGE embeddings, and a locally hosted Llama 3.2 3B model via Ollama for grounded enterprise document question answering.
Built production-oriented FastAPI and Streamlit interfaces with automated FAISS index rebuilds, document source tracking, health checks, logging, and configurable application settings.
Implemented LLMOps observability using Prometheus, Grafana, and Opik for application metrics, operational dashboards, and end-to-end RAG/LLM request tracing, with Docker-based deployment.
